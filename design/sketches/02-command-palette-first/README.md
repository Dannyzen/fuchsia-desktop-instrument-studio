## Variant: Command Palette First

### Design stance
Quiet tiles, loud command surface. Most power lives in one searchable palette.

### Key choices
- Layout: sparse top bar, large tiled cards, center command palette overlay
- Typography: Inter + mono keycaps
- Color: Linear-like dark canvas with violet accent
- Interaction: Ctrl/Cmd-K opens palette; arrow/enter runs focus, move, settings, launch

### Trade-offs
- Strong at: expert speed, low permanent chrome, shortcut-centric future
- Weak at: discoverability for new users without coaching or command hints

### Best for
- After global shortcut policy lands and keyboard is the primary input contract
