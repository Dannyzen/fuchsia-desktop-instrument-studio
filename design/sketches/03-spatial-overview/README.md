## Variant: Spatial Overview

### Design stance
Current tiles remain source of truth; overview is a projection for orientation and rearrangement.

### Key choices
- Layout: live tiled stage under a workspace/overview board
- Typography: airy Inter headings, mono badges
- Color: deep blue-cyan spatial palette
- Interaction: toggle overview, jump via thumbnails, reveal split/stack/float insert targets

### Trade-offs
- Strong at: spatial memory, workspace switching, future split-tree UX
- Weak at: more motion/state choreography to implement carefully

### Best for
- The phase where workspaces, stacks, and drop targets become first-class
