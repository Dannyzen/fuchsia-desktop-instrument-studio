## Variant: Instrument Studio

### Design stance
A finished desktop shell with always-visible chrome, shared controls, and unmistakable active-window treatment.

### Key choices
- Layout: top workspaces, left launcher rail, 2x2 tiled apps, bottom inspector
- Typography: Inter + JetBrains Mono
- Color: near-black panels, cyan confirmed-focus, violet secondary
- Interaction: click tiles to focus, toggles/sliders apply live WM settings, workspace pills switch contexts

### Trade-offs
- Strong at: product polish, discoverability, settings richness
- Weak at: screen chrome cost, less pure keyboard minimalism

### Best for
- The default Fuchsia desktop direction if we want it to feel like a real OS shell immediately
